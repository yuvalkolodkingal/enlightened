# התקנה

[English](Installation)

1. התקינו **NeoForge 21.1** ל**מיינקראפט 1.21.1** (נבנה מול NeoForge 21.1.256; כל 21.1 מאז עובד), או, מאז 1.0.29, **NeoForge 21.4** ל**מיינקראפט 1.21.4** (נבנה מול 21.4.161), או, מאז 1.0.31, **NeoForge 21.5** ל**מיינקראפט 1.21.5** (נבנה מול 21.5.101), או, מאז 1.0.32, **NeoForge 21.11** ל**מיינקראפט 1.21.11** (נבנה מול 21.11.48), או, מאז 1.0.33, **NeoForge 26.3** ל**מיינקראפט 26.3** (נבנה מול 26.3.0.102; מיינקראפט 26.3 עצמה צריכה Java 25). זה אותו קובץ לחמשתן: המוד מגלה באיזו מיינקראפט הוא רץ ומפעיל את העותק הנכון של עצמו.
2. שימו את `enlightened-<version>.jar` (מדף ה-[Releases](../../releases), או [בנוי מקוד המקור](Building-from-Source-HE)) בתיקיית `mods`.
3. למשחק מרובה משתתפים שימו את אותו jar גם בשרת: לקוח ושרת עם גרסאות שונות של המוד מסרבים זה לזה.

לא צריך שום דבר נוסף. למוד אין תלויות מלבד NeoForge.

אפשרויות השרת נמצאות ב-`world/serverconfig/enlightened-server.toml` אחרי שעולם נפתח (במיינקראפט 26.3: `config/enlightened-synced.toml`): ראו [הגדרות שרת](Server-Configuration-HE).
